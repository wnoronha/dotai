# Gtan design consultation

## Flow

1. Pre-checks: read existing `DESIGN.md` if present. Update, start fresh, or cancel — record the choice.
2. Product context: what the surface must do, for whom.
3. Landscape research: prior art, moodboard of themes and layouts.
4. Proposal: full system (aesthetic, typography, color, layout, spacing, motion) with preview.
5. Write `DESIGN.md` as the shared contract. Downstream tools read it.

## Rules

- Research before proposing. No generic system without landscape evidence.
- Mockups are illustrative, not shippable. Real build follows `poteto-mode`.
